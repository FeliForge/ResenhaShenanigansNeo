# AGENTS.md

This project is a multiplayer game built with React, Vite, and Cloudflare Workers / Vercel.

## Key directories
- `src/components/game/` - Game UI and logic components
- `src/lib/game/` - Core game systems
- `src/data/` - Game data (characters, quests, shop)
- `src/lib/multiplayer/` - P2P multiplayer
- `src/integrations/supabase/` - Auth and backend

## Commands
- `bun install`
- `bun run dev`
- `bun run build`
